✅ React Todo Application

A modern, responsive Task Management Application built with React.js.
This project demonstrates the core concepts of React: component-based architecture, state management, and lifecycle methods.

🛠 Tech Stack

Core: React.js (Create React App), JavaScript (ES6+).

Styling: CSS Modules for component-scoped styling.

Material UI: Used for icons and some UI elements.

Package Manager: NPM.

✨ Features

Add Tasks: Simple input field to create new to-do items.

Mark as Done: Interactive checkboxes to complete tasks.

Delete Tasks: Remove items from the list.

Filter: View Active, Completed, or All tasks (if implemented).

Responsive: Looks good on mobile and desktop.

📂 Project Structure

src/
├── components/      # Reusable UI components
│   ├── App/         # Main container
│   ├── InputItem/   # Input field logic
│   ├── ItemList/    # List rendering
│   ├── Item/        # Single task component
│   ├── Footer/      # Filter controls
│   └── About/       # Information page
├── index.js         # Entry point
└── index.css        # Global styles


💡 Key Learnings

State Management: Using React Hooks (useState, useEffect) to manage the list of tasks.

Component Lifecycle: Understanding how React updates the DOM.

Props Drilling: Passing data from parent to child components efficiently.

CSS Modules: Writing modular CSS to avoid class name conflicts.

💻 How to Run Locally

Clone the repository:

git clone [https://github.com/Golubtsov-Sergey/todo-react-app.git](https://github.com/Golubtsov-Sergey/todo-react-app.git)


Navigate to the project folder:

cd todo


Install dependencies:

npm install


Start the development server:

npm start


The app will open at http://localhost:3000.
